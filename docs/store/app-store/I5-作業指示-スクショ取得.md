## 手順

```bash
# 0) セットアップ（リポジトリルートで。apps/mobile 内で pnpm install しない）
pnpm install

# 1) シミュレータ起動（スクリプトの既定は iPhone 16 Pro Max = 6.9"/1320x2868）
xcrun simctl boot "iPhone 16 Pro Max" ; open -a Simulator

# 2) ストアショット用ビルド（サンプルデータ有効・コーチマーク無効・広告 OFF）
LANG=en_US.UTF-8 \
  EXPO_PUBLIC_ENABLE_SAMPLE_DATA=1 EXPO_PUBLIC_DISABLE_COACH_MARKS=1 \
  pnpm --filter mobile exec expo run:ios --configuration Release

# 3) オンボーディング（地域選択）を一度済ませる。未完了だと
#    どのルートを開いても「ようこそ」画面が出てしまう

# 4) 取得（9:41・満充電にステータスバーを固定して 7 枚）
node scripts/release/capture-ios-screenshots.mjs
```

> **`LANG` を必ず渡す。** ロケールが未設定（`LANG=""` / `LC_CTYPE=C`）の Mac では
> CocoaPods が `Unicode Normalization not appropriate for ASCII-8BIT`
> （`Encoding::CompatibilityError`）で落ちる。Expo は pod install の失敗を
> 警告扱いのまま xcodebuild へ進むので、**「The sandbox is not in sync with the
> Podfile.lock」まで行って初めて気付く**（2026-08-14 に踏んだ）。

- **`EXPO_PUBLIC_ADMOB_*` は付けない。** ストア掲載物にテスト広告が写り込む事故を防ぐ
  （未設定なら広告は一切出ない設計。`config.ts` の `ADMOB_ENABLED` 参照）
- 画面構成と順序は Android と同一（スクリプトの `SHOTS` 配列が正）:
  ホーム → 栽培一覧 → 栽培詳細 → 収穫アルバム → 作物ガイド → カレンダー → 資材

### URL 確認ダイアログ（iOS 17+）— 取得中に手が要る

`simctl openurl` でカスタムスキームを開くと SpringBoard が
**「"さいえん手帳" で開きますか?」** を出し、**「開く」を押すまでアプリは起動しない。**
しかも毎回は出ず、直前に確定していると一定時間は抑制される（＝出たり出なかったりする）。
`simctl` に入力注入は無く、AppleScript のクリックは補助アクセス許可が要るため、
ここだけは自動化できない。

- スクリプトは**アプリが前面に出るまで待ってから撮る**。待ちに入ると
  「開く」を押すよう促すので、シミュレータ側で押す（既定 90 秒でタイムアウト）
- タイムアウトしたショットは `FAILED` になり、スクリプトは非ゼロ終了する。
  **黙って別の画面が撮れることはない**（以前の実装は 7 枚とも
  「ホーム画面＋確認ダイアログ」を撮って captured と報告した）

### サイズについて（2026-08-14 に ASC の実フォームで確認）

バージョンページのアップロード枠は **6.5 インチ表記**で、受理サイズとして
`1242×2688 / 2688×1242 / 1284×2778 / 2778×1284` が明記されていた。
16 Pro Max の **6.9"（1320×2868）はメディアマネージャー経由でアップロード可能**
（枠の右上「メディアマネージャーですべてのサイズを表示」）。

- **既定のまま 16 Pro Max で取る**（スキルの方針どおり）
- もし Windows 側のアップロードで 6.9" が弾かれた場合のフォールバックだけ用意:
  `xcrun simctl boot "iPhone 16 Plus"`（1284×2778 = 受理サイズに一致）で
  `--udid` を付けて取り直す。**先回りして両方は取らない**（承認対象が倍になる）

## ついでにやる I5 描画確認（スクショと同じビルドで一巡）

Windows では検証できなかった項目（`.claude/skills/ios-release` §1 の重点）:

結果（2026-08-14・iPhone 16 Pro Max / iOS 18.5・Release ビルド）:

- [x] セーフエリア（ノッチ・ホームインジケータ）に文字/ボタンが潜り込まない
- [x] `borderRadius` が効いている（Android で四角に落ちた実績のある UI）
- [x] ボトムシートがジェスチャーバーに飲まれない
      — カレンダーは**アプリ起動中にホームから開くと iOS ではページシート**になり、
      上部にシートの余白が出る（Android は全画面）。崩れではなく iOS の標準挙動。
      掲載スクショはディープリンクのコールドスタートで撮るため全画面になり、
      Android 版と同じ見え方に揃う
- [x] 収穫アルバムの作物フィルタ（横スクロール帯）が縦に伸びない（資材の分類チップも同様）
- [x] 通知の許可ダイアログが出る・リマインダーが発火する
      — 許可直後に資材残量のリマインダーが発火するのを確認
- [x] バックアップの書き出し → 復元の往復（73.7 KB を書き出し→復元、データ維持）

**問題を見つけたら、スクショ PR とは別に issue 化する**（修正で止めない —
スクショ提出が律速のため。ただし審査に落ちるレベルの崩れなら PR に明記して相談）。
