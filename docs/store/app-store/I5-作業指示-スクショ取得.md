## 手順

```bash
# 0) セットアップ（リポジトリルートで。apps/mobile 内で pnpm install しない）
pnpm install

# 1) シミュレータ起動（スクリプトの既定は iPhone 16 Pro Max = 6.9"/1320x2868）
xcrun simctl boot "iPhone 16 Pro Max" ; open -a Simulator

# 2) ストアショット用ビルド（サンプルデータ有効・コーチマーク無効・広告 OFF）
EXPO_PUBLIC_ENABLE_SAMPLE_DATA=1 EXPO_PUBLIC_DISABLE_COACH_MARKS=1 \
  pnpm --filter mobile exec expo run:ios --configuration Release

# 3) 取得（9:41・満充電にステータスバーを固定して 7 枚）
node scripts/release/capture-ios-screenshots.mjs
```

- **`EXPO_PUBLIC_ADMOB_*` は付けない。** ストア掲載物にテスト広告が写り込む事故を防ぐ
  （未設定なら広告は一切出ない設計。`config.ts` の `ADMOB_ENABLED` 参照）
- 画面構成と順序は Android と同一（スクリプトの `SHOTS` 配列が正）:
  ホーム → 栽培一覧 → 栽培詳細 → 収穫アルバム → 作物ガイド → カレンダー → 資材

### サイズについて（2026-08-14 に ASC の実フォームで確認）

バージョンページのアップロード枠は **6.5 インチ表記**で、受理サイズとして
`1242×2688 / 2688×1242 / 1284×2778 / 2778×1284` が明記されていた。
16 Pro Max の **6.9"（1320×2868）はメディアマネージャー経由でアップロード可能**
（枠の右上「メディアマネージャーですべてのサイズを表示」）。

- **既定のまま 16 Pro Max で取る**（スキルの方針どおり）
- もし Windows 側のアップロードで 6.9" が弾かれた場合のフォールバックだけ用意:
  `xcrun simctl boot "iPhone 16 Plus"`（1284×2778 = 受理サイズに一致）で
  `--udid` を付けて取り直す。**先回りして両方は取らない**（承認対象が倍になる）

## ついでにやる I5 描画確認（スクショと同じビルドで一巡）

Windows では検証できなかった項目（`.claude/skills/ios-release` §1 の重点）:

- [ ] セーフエリア（ノッチ・ホームインジケータ）に文字/ボタンが潜り込まない
- [ ] `borderRadius` が効いている（Android で四角に落ちた実績のある UI）
- [ ] ボトムシートがジェスチャーバーに飲まれない
- [ ] 収穫アルバムの作物フィルタ（横スクロール帯）が縦に伸びない
- [ ] 通知の許可ダイアログが出る・リマインダーが発火する
- [ ] バックアップの書き出し → 復元の往復

**問題を見つけたら、スクショ PR とは別に issue 化する**（修正で止めない —
スクショ提出が律速のため。ただし審査に落ちるレベルの崩れなら PR に明記して相談）。

## 注意

- スクショは**ストア公開物**。アップロード前にユーザー承認が必須（DoD 3）。
  Mac 側は取得とコミットまで — ASC へのアップロードはしない
- サンプルデータの写真 4 枚は EXIF/GPS ゼロを確認済み（2026-08-14・AAB 検証）。
  スクショ自体に個人情報が写る要素はサンプルデータ構成上ない想定だが、
  ステータスバー固定（9:41）になっていることだけ目視すること
- シミュレータビルドが `saientecho://` ディープリンクを受けない場合は
  一度アプリを手で起動してから再実行（初回インストール直後の既知の揺らぎ）
