## 1. データ全般

- **アカウント登録なし。** 氏名・メールアドレス・電話番号は一切収集しない
- 栽培記録・作業ログ・収穫・資材・買い物リストは**端末内のみ**。提供者のサーバーへ
  送信しないので、申告対象外
- 提供者は自前のサーバーを持たない（インフラ設計 §2）

## 2. 広告（Google AdMob）

| 項目           | 申告                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| データの種類   | **デバイス ID またはその他の ID** → 広告 ID                              |
| 収集 / 共有    | **収集する** および **第三者と共有する**（Google）                       |
| 目的           | 広告またはマーケティング、不正行為の防止・セキュリティ・コンプライアンス |
| 必須 / 任意    | 任意（利用者は端末設定またはアプリ内でオプトアウトできる）               |
| 転送時に暗号化 | はい                                                                     |
| 削除の要求     | 端末の広告 ID の削除で対応（アプリ側に保持しない）                       |

あわせて AdMob が取得しうるもの（Google の SDK 側の申告に準じる）:

- **アプリのアクティビティ / 端末情報**: 機種・OS・アプリのバージョン等（広告の配信可否の判定）
- **おおまかな位置情報**: IP アドレスから推定される国・地域

> 入力時の注意: Play Console には Google が提供する
> [SDK インデックス / データ開示ガイダンス](https://support.google.com/googleplay/android-developer/answer/10787469)
> があり、AdMob 分の推奨申告が示される。**提出前に最新のガイダンスを確認して合わせること**
> （SDK の更新で申告項目が変わることがある）。

## 3. 写真を送る機能（サーバー経由）

**写真を端末外へ送る機能は 2 つある。** どちらも利用者が実行したときのみ発生し、
データの種類・目的・共有先は同じなので、Play のフォーム上は 1 つの申告にまとまる。

| 機能                                                  | 実装              | 送るもの                   |
| ----------------------------------------------------- | ----------------- | -------------------------- |
| **AI 相談**（WBS 3.10 / 3.11）                        | `/garden/consult` | 写真・作物名・相談文       |
| **写真の読み取り**（#148 / WBS 4.16・**1.1 で追加**） | `/garden/harvest` | 収穫の写真・記録先の作物名 |

> **「写真の読み取り」は UI で AI と名乗らない**（#143 の決定）が、
> **申告とプライバシーポリシーでは外部送信として扱う**。
> 画面表記と申告を混同しないこと — 表記の方針は申告義務を変えない。
>
> **1.2 で `/garden/identify`（写真から栽培を登録）が加わる予定**（#139）。
> 同じ種類・同じ目的・同じ共有先なのでフォームの回答は変わらないが、
> **リリース時にこの表を更新すること**。

| 項目           | 申告                                                                         |
| -------------- | ---------------------------------------------------------------------------- |
| データの種類   | **写真と動画** → 写真 / **アプリのアクティビティ** → その他（相談テキスト）  |
| 収集 / 共有    | 収集する・**第三者と共有する**（Google — Gemini API で処理）                 |
| 目的           | アプリの機能                                                                 |
| 必須 / 任意    | **任意**（機能を使わなければ送信されない）                                   |
| 転送時に暗号化 | はい（HTTPS）                                                                |
| 削除の要求     | サーバーは保存しない（下記エフェメラル処理）ため、削除対象のデータが残らない |

- 経路: 端末 → 提供者管理の推論サーバー（Railway・ステートレス）→ Google Gemini API
- サーバーは**リクエストの中継のみ**で、写真・テキストをディスクに保存しない
  （メモリ内で処理し応答後に破棄 — Play の定義でいうエフェメラル処理。
  ただしフォームでは保守的に「収集する」で申告する）
- 相談結果も端末にのみ表示され、サーバー側に履歴は残らない
- 利用回数の制限（無料枠）のため、サーバーが接続元 IP を 24 時間メモリ内で数える
  （永続化しない）

> **入力の指針**: 「データは転送中に暗号化されますか」= はい /
> 「ユーザーはデータの削除をリクエストできますか」= サーバーに保存しないため
> 該当データなし（フォーム上は「はい」を選び、ポリシーにその旨を記載済み）。

## 4. 申告しないもの（根拠つき）

| 項目                       | なぜ申告しないか                                                 |
| -------------------------- | ---------------------------------------------------------------- |
| 位置情報（精確）           | 端末の位置情報権限を要求していない。地域設定は 3 択の手入力      |
| 連絡先・カレンダー         | アクセスしていない                                               |
| 個人情報（氏名・メール等） | 収集していない。アカウント機能が無い                             |
| 栽培記録・写真そのもの     | 端末内のみ（§3 の AI 機能を使った場合を除く）                    |
| クラッシュlog / 診断情報   | 現時点で収集ツールを入れていない。**入れたらここを更新すること** |
