## 背景

`harness-reviewer` エージェントによる `.claude/` 全体の監査。スキル 13・エージェント 6・ワークフロー 1 の計 20 アセットを Harness 7軸で採点。**総合 14/21（Intermediate）**、機械チェックは ERROR 0 / WARN 0。減点はほぼ全て移植残骸に由来（20 アセット中 15 が要書き換え）。

このセッションで受けた指摘を遡って記録したもの。以後は受けた時点で記録する。

## 指摘

### 1. だいどこの実資産を触る参照が 4 スキルに残っている

- **状態**: done
- **重大度**: 高
- **指摘**: `deploy-server` / `incident-rollback` / `release-play` の `railway --service daidoko`、`monetize-golive` の AdMob ユニット ID とパブリッシャー ID が残存。実行するとだいどこ本番へのデプロイ・巻き戻し、だいどこの広告ユニットの配線（ポリシー違反）が起こりうる。
- **調査**: 実物を grep して全件確認、指摘どおりだった。前コミット `c962e4f` のメッセージは「だいどこの実資産を触りうる参照を全て置き換え」としていたが**過大な主張**で、grep パターンが引用符付きの識別子しか拾わず `--service daidoko` のような裸の参照を素通りさせていた。
- **判断**: 対応する。さいえん手帳の Railway サービス・AdMob アカウントは未作成のため、実値ではなく `<... — 未作成>` のプレースホルダに置換する。あわせて再発防止として `foreign-app-identifier` 検出を検証器に追加し pre-commit へ配線する（人手レビュー頼みをやめる）。
- **対応**: `0eeccc0`（PR #50）
