## 背景

ホームの「育てているもの」に進行帯（植え付け → 収穫の目安）を実装した初版を、
**実機の実データで表示してから**利用者目線でレビューした。ユーザーの実端末には
キュウリ 50 日目・トマト 65 日目・アオジソ 80 日目・エダマメ 90 日目が入っており、
収穫の目安（40 / 60 / 40 / 80 日）を**全員が超えていた** — この状況が机上では
見落としていた問題を全部あぶり出した。あわせて直前に入れたリマインダーの
「記録」ボタンも見直した。

## 指摘

### 1. 4 枚中 4 枚が同じ「怒られ」状態になり、情報量がゼロになる

- **状態**: done
- **重大度**: 高
- **影響**: ホームを開くたびに全カードがオレンジの満杯帯＋「過ぎています」で、差が読めないうえに咎められている感じだけが残る
- **指摘**: 実データでは全栽培が目安超過。しかも**キュウリは収穫を 4 回記録済み**なのに「収穫の目安を 10 日 過ぎています」と出る。キュウリ・シソのような採り続ける作物は、初収穫後もシーズン中ずっと育っているのが正常で、この文言はシーズンの残り全部で出続ける（オオカミ少年）。`next-action.service` は**初収穫を記録したら収穫提案を止める**先例があるのに、帯は harvests を見ていなかった。
- **判断**: 対応する。状態を 4 値に分ける — `growing`（目安前）/ `due`（未収穫で超過 = 採りどきの確認を促す・収穫色）/ `harvesting`（収穫記録あり = 正常・緑のまま「収穫中」）/ `none`（目安なし）。
- **対応**: `growth-progress.service` に状態遷移を実装し、実 SQLite テスト 5 件で固定。

### 2. 文言がカード幅に入らず、肝心の数字が見えない

- **状態**: done
- **重大度**: 高
- **影響**: 「収穫の目安を 10 日 過ぎています」（18 文字）がカード幅 92px で「収穫の目安…」に切れ、**日数がひとつも画面に出ない**
- **指摘**: 初版の `describeProgress` は説明調で長すぎた。何の話かは帯そのものが示すので、文字は最小限でよい。
- **判断**: 対応する。`あと15日` / `採りどき` / `収穫中・50日目` / `30日目` の短文に全面差し替え。

### 3. 作物名が合っているのに帯が出ない栽培がある（マスター未リンク）

- **状態**: done
- **重大度**: 高
- **影響**: 利用者から見て 3 つが**静かに**壊れる（下記）。進行帯を出すまで可視化する画面が無く、気づけなかった
- **指摘**: 当初は「候補を選んだときだけ cropId が付く」と見立てたが、調査したら**もっと悪かった**。栽培フォームには**作物名のサジェストも照合も一切無い**（`PlantingForm.tsx` に `cropId` の語が 0 件）。`cropId` が付くのは (1) 作物ガイドの「この作物を育てはじめる」から来たとき (2) 編集画面が既存レコードの値を初期値に載せたとき の 2 経路だけで、**「トマト」と一字一句正確に手打ちしても null のまま**。`planting.service` は `cropId: input.cropId ?? null` を素通しするだけで `crops` を引かない。
- **調査**: `cropId` が null だと壊れるのは 3 つで、いずれも `crop_guides` / `crops` への innerJoin が原因。
  1. **つぎの作業** — 提案が 1 件も生成されず、`NextActionCard` が `return null` するので**カードごとホームから消える**（空状態の文言すら出ない）
  2. **進行帯** — 帯が出ないうえ、**帯の中に描く作業ログのドットも消える**。記録しても見た目が何も変わらない
  3. **収穫の既定単位** — 選ばれず、単位未選択で保存された数量は `getHarvestTotals` から**静かに除外される**

  今月の菜園仕事・作物ガイド・リマインダーは `plantings.cropId` を見ていないので無傷。
  照合関数 `matchCropMaster` は既に `planting-draft.service`（写真からの登録）にあったが、**そこからしか呼ばれていなかった**。

- **付随して見つかった不整合**: 作物名を書き換えても `cropId` が追随しない。「トマト」を「ナス」に直しても `cropId='crop-tomato'` が残り、**トマトの暦で助言する**行ができる。
- **判断**: 対応する。進行帯だけの問題ではなく、出荷済み機能が黙って効かなくなる欠陥のため。
- **対応**: `crop-match.service.ts` を新設し、**保存時に作物名を正としてマスターへ引き直す**（完全一致 → 別名 → 包含）。別名表 19 語（アオジソ/大葉→シソ、枝豆→エダマメ、ミニトマト→トマト 等）を追加。`planting-draft.service` の重複実装をここへ寄せた。**自由入力は禁じない**（当たらなければ null のまま）。

### 3b. 包含照合が別作物へ誤爆する

- **状態**: wontfix
- **重大度**: 低
- **影響**: 芽キャベツ → キャベツ、ヘビイチゴ → イチゴ に寄る
- **指摘**: 包含は「ミニトマト → トマト」を拾うために要るが、別作物まで巻き込む。
- **判断**: いまは直さない。暦が近い作物へ寄るぶん実害が小さく、正すなら別名表ではなく**マスターに品目を足す**のが筋（芽キャベツは別作物）。テストで挙動を固定し、コメントに理由を残した。

### 4. 今日マーカー（▲）が右端で切れて欠けに見える

- **状態**: done
- **重大度**: 低
- **指摘**: 目安超過では塗りが満杯になり、▲ が SVG の外にはみ出て描画されない／半分だけ残る。満杯の帯では「今日」を示す意味も無い。
- **判断**: 対応する。位置をクランプし、満杯（ratio >= 1）では出さない。

### 5. リマインダーの 1 タップ記録に確認の返事が無い

- **状態**: done
- **重大度**: 低
- **影響**: バッジが「記録済み」に変わるだけで、誤タップに気づく手掛かりが弱い（取り消しは作業ログを開いて削除するしかない）
- **指摘**: 栽培詳細のクイック記録は「水やりを記録しました」トーストを出すのに、ホームは無言だった。
- **判断**: 対応する。同じトーストを出す。

### 6. 「90 日目」の表記ゆれ

- **状態**: done
- **重大度**: 低
- **指摘**: `describeProgress` 経由になった栽培だけ「90 日目」（半角スペース入り）になり、他画面の「90日目」と不揃いだった。
- **判断**: 対応する。スペースなしに統一。

## うまくいっているもの（維持する）

- リマインダーの「記録」ボタン: 1 タップで `✓ 記録済み` に変わり、画面遷移しない。二度押し防止も実機で確認
- 帯の下の作業ログドット: 76px 幅でも視認できる。同じ日の複数作業を 1 つに畳む判断は正しかった
- 目安なし（自由入力）で 0% の帯を出さない判断 — ただし指摘 3 の照合改善が本筋
