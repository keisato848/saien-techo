# さいえん手帳 利用規約

制定日: 2026-07-31

この利用規約(以下「本規約」)は、家庭菜園記録アプリ「さいえん手帳」(以下「本アプリ」)の利用条件を定めるものです。本アプリをご利用いただいた時点で、本規約に同意したものとみなします。

## 1. 本アプリの位置づけ

本アプリは、個人開発者が提供する家庭菜園の記録・管理アプリです。栽培記録、収穫記録、栽培暦にもとづくアドバイス、AI による診断・相談などの機能を提供します。

本アプリの中心的な機能は利用者の端末内で完結します(ローカルファースト)。一部の機能(AI 診断・AI 相談など)のみ、提供者が運用するサーバーおよび外部の AI サービスを利用します。

## 2. 提供の停止・終了(重要)

**本アプリおよび本アプリに関連するサーバー機能は、予告なく、いつでも、内容の変更・提供の中断・提供の終了を行うことがあります。**

- 提供者は、本アプリおよびサーバー機能を**継続して提供することを保証しません**。
- 提供者は、変更・中断・終了について、事前の通知を行う義務を負いません。
- 提供者は、変更・中断・終了によって利用者または第三者に生じた損害について、**一切の責任を負いません**。

本アプリは個人開発者が無償で提供しているものであり、提供者の事情(開発の継続が困難になった場合、運用コストの負担が困難になった場合、外部サービスの提供条件が変更された場合など)により、随時これらを行うことがあります。

### 2.1 サーバー機能が終了した場合

サーバー機能(AI 診断・AI 相談)が終了した場合でも、端末内で完結する機能(栽培記録、作業ログ、収穫記録、写真アルバム、栽培暦、リマインダーなど)は引き続きご利用いただけます。ただし、これについても第 2 条のとおり継続を保証するものではありません。

- AI による診断・推定は誤る場合があります。
