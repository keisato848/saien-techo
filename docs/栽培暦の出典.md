# 栽培暦・作物ガイドの出典と検証記録（WBS 3.1 / 判断②）

> 作成: 2026-08-06、v4 追記: 2026-09-05。マスターの実体は `apps/mobile/src/db/crop-master.ts`（v4・50 品目）。
> 出典の定数は `CROP_MASTER_REFERENCES`（各資料に `id`）、作物ごとの対応は各作物の `sourceIds`、
> アプリ内表示は `CROP_MASTER_ATTRIBUTION` と作物ガイド詳細の「この作物の出典」。

## 方針

- 開発者・利用者とも園芸の専門家ではないため、**人手レビューの代わりに公的資料と
  突き合わせて**内容を担保する（判断②の決定・2026-08-06）
- 数値は各資料の作型表を**転載せず**、家庭菜園向けの「月単位の目安」として独自に
  まとめ直す。品種・年ごとの気候で前後する旨は利用規約の免責と、アプリ内の
  出典表示（「〜公開資料をもとにした目安です」）で伝える
- アプリ内表示: 「今月の菜園仕事」カードの脚注（実装済み）と、作物ガイド画面
  （WBS 3.3）の出典一覧（予定）
- 疑問点を AI に確認する機能は v1.5 の AI 栽培相談（R15 / WBS 4.2）で提供する

### 新しい列の根拠

| 列                               | 根拠の取り方                                                                                          |
| -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 適温（発芽・生育）               | 果菜は長野の表。葉物・根菜は各資料の「生育適温」の記述と定説（冬野菜 15〜20 ℃・夏野菜 20〜30 ℃）      |
| 収穫の幅                         | 目安日数を中央に、資料の「○〜○日」または品種差を ±15〜20% で置いた。目安 ≤ 幅の最大を構造テストで強制 |
| 追肥間隔                         | 果菜は「2 週間に 1 回」（JA 西春日井・木曽）、葉物で 1 回で済むものは null                            |
| 作業（摘芯・支柱・土寄せ…）      | 各資料の作業記述を「植え付けからの日数」に読み替えた。日数は目安で、次の作業は 2 週間だけ出す         |
| 連作年数                         | 定説（ナス科 3〜4 年・ウリ科 2〜3 年・マメ科 2〜4 年・ショウガ 4 年）。連作に強いものは 0             |
| 多年草                           | ニラ・ミョウガだけ。収穫日数を持たず、暦の収穫窓は「定着後の毎年の採りどき」                          |
| 編集者判断（初心者・プランター） | **出典なし**。一覧の絞り込みにだけ使い、暦や次の作業の判定には使わない                                |

### 既存 30 品目への影響

暦（月）と株間・追肥・収穫の日数は v3 から**変えていない**。足したのは新しい列だけ。

## 更新の手順

1. 資料を確認して `crop-master.ts` を補正
2. `CROP_MASTER_VERSION` を上げる（据え置くと配布済み端末に反映されない）
3. この文書の補正表に追記
4. 構造テスト（`crop-master.test.ts`）が緑のままであることを確認
