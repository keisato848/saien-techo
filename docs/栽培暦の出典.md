# 栽培暦・作物ガイドの出典と検証記録（WBS 3.1 / 判断②）

> 作成: 2026-08-06。マスターの実体は `apps/mobile/src/db/crop-master.ts`（v3）。
> 出典の定数は `CROP_MASTER_REFERENCES`、アプリ内表示は `CROP_MASTER_ATTRIBUTION`。

## 方針

- 開発者・利用者とも園芸の専門家ではないため、**人手レビューの代わりに公的資料と
  突き合わせて**内容を担保する（判断②の決定・2026-08-06）
- 数値は各資料の作型表を**転載せず**、家庭菜園向けの「月単位の目安」として独自に
  まとめ直す。品種・年ごとの気候で前後する旨は利用規約の免責と、アプリ内の
  出典表示（「〜公開資料をもとにした目安です」）で伝える
- アプリ内表示: 「今月の菜園仕事」カードの脚注（実装済み）と、作物ガイド画面
  （WBS 3.3）の出典一覧（予定）
- 疑問点を AI に確認する機能は v1.5 の AI 栽培相談（R15 / WBS 4.2）で提供する

### 未補正（標準的な定説の範囲と判断）

中間地・暖地の葉物・果菜・越冬もの（イチゴ・タマネギ・ニンニク・スナップエンドウ）は
一般的な作型の定説どおりで、複数資料間の差も月単位では吸収される範囲。
v1.0 公開までに気づきがあれば同じ手順（資料 → 補正 → この表に追記 → バージョン上げ）で直す。

## 更新の手順

1. 資料を確認して `crop-master.ts` を補正
2. `CROP_MASTER_VERSION` を上げる（据え置くと配布済み端末に反映されない）
3. この文書の補正表に追記
4. 構造テスト（`crop-master.test.ts`）が緑のままであることを確認
