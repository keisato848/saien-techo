# さいえん手帳 — 画面設計

> 作成: 2026-08-03（WBS 1.4）
> ステータス: v0.1 Alpha の 3 画面のみ確定。以降の画面は各 WBS 着手時に追記する
> 比較モック: `mockup/palette-compare.html`（ブラウザで直接開ける）

---

## 1. 配色

**若葉を既定とする**（2026-08-03 決定）。4 案をモックで見比べて選定した。

| 案       | 性格                                                          | 状態     |
| -------- | ------------------------------------------------------------- | -------- |
| **若葉** | 春の新芽の黄緑。彩度が高く軽い。「これから育つ」印象          | **既定** |
| 苗床     | セージ × 土色。紙の菜園手帳の延長。彩度が低く写真が主役になる | 選択可   |
| 深緑     | 青みの深い葉緑。輪郭が硬く、記録ツールとしての精度が出る      | 選択可   |
| 土       | 土の黒に葉の黄緑。夕方の屋外で見やすい暗色案                  | 選択可   |

4 案とも `apps/mobile/src/constants/theme.ts` の `PALETTES` に実装済みで、`ACTIVE_PALETTE`
を変えるだけで全画面が入れ替わる。実機で比較するときはビルド時に環境変数で指定する。

```bash
EXPO_PUBLIC_PALETTE=naedoko node scripts/agent/build-android.mjs --arch x86_64
```

### トークンの命名

意味的な名前（`accent` / `ink` / `surface` …）を新しい画面で使う。
`gold` / `paper` などのだいどこ由来のキーは**移行期間の別名**として残してあり、
recipes 系の画面が消えた時点（WBS 1.5 完了後）に削除する。

`harvest` はアクセントとは別系統の色。収穫は本アプリの中核（要件 §1 の 3 本柱）で、
作業ログと視覚的に区別する必要があるため、緑ではなく暖色を当てている。

### フォント

**和文に webfont は積まない。** APK が膨らむうえ、和文はシステムフォントの方が読みやすい。
`Fonts.system` のみを持ち、ウェイトとサイズで階層を作る。

だいどこは `Cormorant Garamond` をワードマークに使っていたが、さいえん手帳では
装飾フォントを持たない方針とし、`Fonts.brand` は削除した。

## 2. タイポグラフィ

| 名前   | px  | 用途                                 |
| ------ | --- | ------------------------------------ |
| `xxs`  | 11  | タグチップ・最小補助ラベル           |
| `xs`   | 12  | タイムスタンプ・メタ情報・経過日数   |
| `sm`   | 13  | フォームラベル・カード副情報         |
| `base` | 15  | 本文（作物名・メモ・カードタイトル） |
| `md`   | 17  | セクションヘッダー・ボタン CTA       |
| `lg`   | 20  | 画面タイトル・栽培名（詳細）         |
| `xl`   | 24  | ヒーロー数値（収穫数など）           |

ウェイトは `regular` 400 / `medium` 500 / `semibold` 600 の 3 段階のみ。

## 3. 画面構成

### タブ

| タブ   | 画面                                               | 要件                  |
| ------ | -------------------------------------------------- | --------------------- |
| ホーム | 今日の菜園（次の作業・今月の菜園仕事・最近の記録） | R05 / R08 / R10       |
| 栽培   | 栽培一覧 → 栽培詳細                                | R01 / R03 / R04 / R06 |
| 収穫   | 収穫アルバム                                       | R07                   |
| 設定   | 設定                                               | R13 ほか              |

**収穫を独立タブにした理由**: 要件 §1 で収穫は 3 本柱の 1 つに格上げされている。
栽培の中に畳むと「今日の採れたてを撮る」導線が 2 階層深くなり、R06 の
「最短 3 タップ」を満たせない。

## 4. 画面詳細（v0.1 Alpha）

### S01 ホーム — 今日の菜園

上から順に、**行動を促すもの → 季節の情報 → 履歴**。

1. **つぎの作業**（アクセント面のカード）— 栽培ごとに植え付けからの経過日数と
   作物ガイドを突き合わせた提案。「記録する」で該当の記録画面へ、「あとで」で消す（R10）
2. **今月の菜園仕事** — 作物暦から今月まける種・植えられる苗（R08）
3. **さいきんの記録** — 作業ログと収穫を時系列で 3 件（R05）

収穫は左のドットを暖色にして作業ログと区別する。

**未確定**: 初回起動時（記録ゼロ）の表示。空状態は WBS 1.9 で設計する。

### S02 栽培一覧

- 「育成中 / 終了した栽培」の切り替え（R01 のアーカイブ、R03）
- 1 行に 作物名・品種・場所・**経過日数**。経過日数はアクセント色で右端に置く
- 検索は作物名・品種・タグ・場所（FTS5。`planting_fts`）

**未確定**: 並び順の既定。植え付け日の新しい順か、次の作業が近い順か。

### S03 栽培詳細

1. **「やった！」を記録** — 水やり / 追肥 / 剪定 / 防除 / 収穫 の 5 ボタン。
   タップで即記録し、写真とメモは後から足せる（R04 の「1〜2 タップ」）
2. **収穫** — その栽培の収穫写真をグリッド表示。今季の合計を暖色のピルで（R06 / R07）
3. **作業ログ** — 時系列（R04）

**収穫ボタンを 5 つ目に混ぜた理由**: 収穫は作業ログとは別テーブル（`harvests`）だが、
ユーザーにとっては同じ「やったことの記録」。導線を分けると 3 タップに収まらない。
